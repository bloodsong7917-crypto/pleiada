# Плеяда

Организатор творческих проектов для Windows: бесконечная доска с заметками, карточками, картинками, ссылками, файлами, стикерами, стрелками, группами и вложенными досками. Шаблоны для геймдизайна, совместная работа в реальном времени, светлая и тёмная темы.

## Запуск

`dist\Pleiada.exe` — один файл, установка не нужна (требуется Windows 10/11 с WebView2 Runtime; в Windows 11 он есть из коробки).



## Веб-версия с регистрацией и командами

Сервер `dist\server` раздаёт «Плеяду» как сайт: регистрация и вход, команды, проекты внутри команд.

Запуск на своём компьютере: `start-web.cmd` (нужен .NET 10 Runtime) — откроется http://localhost:8787.

- **Команда** — её создаёт любой пользователь и становится владельцем. Остальных добавляют по ссылке-приглашению со страницы команды.
- **Проекты** видят и редактируют только участники команды. Удалить проект может его автор или владелец.
- **Данные** лежат в папке `data`: `accounts.json` (пользователи и команды; пароли хранятся только в виде хэша PBKDF2) и по папке на проект.
- Почта не подтверждается и письма не отправляются, поэтому восстановления пароля нет.
- `PLEIADA_ACCOUNTS=0` отключает регистрацию и возвращает доступ к доскам по ссылке.

Настольное приложение работает без учётных записей. Перенести проект из него в веб-версию: «Экспорт в файл» в меню доски, затем «Импорт из файла» на странице команды.

### Облачный сервер

```
dotnet dist/server/Pleiada.Server.dll
```

Переменные окружения: `PORT` (по умолчанию 8787), `PLEIADA_DATA` (папка с данными, по умолчанию `./data`).

Docker: `docker build -f src/Server/Dockerfile -t pleiada-server .` и `docker run -p 8787:8787 -v pleiada:/data pleiada-server`.

Для доступа из интернета поставьте сервер за HTTPS-прокси (Caddy, nginx) с поддержкой WebSocket.
