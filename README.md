# Плеяда

Организатор творческих проектов для Windows: бесконечная доска с заметками, карточками, картинками, ссылками, файлами, стикерами, стрелками, группами и вложенными досками. Шаблоны для геймдизайна, совместная работа в реальном времени, светлая и тёмная темы.

## Запуск

`dist\Pleiada.exe` — один файл, установка не нужна (требуется Windows 10/11 с WebView2 Runtime; в Windows 11 он есть из коробки).

Проекты хранятся в `%AppData%\Pleiada\boards`.

## Совместная работа

Кнопка **«Поделиться»** на доске:

- **Локальная сеть** — включите переключатель и отправьте ссылку. Участники открывают её в браузере или через «Открыть по ссылке» в приложении. Работает, пока приложение запущено на вашем компьютере; при первом включении Windows спросит разрешение брандмауэра.
- **Облачный сервер** — разверните `dist\server` (или Docker-образ) на хостинге, введите его адрес и нажмите «Опубликовать». Проект переедет на сервер и будет доступен всегда.

Доступ — по ссылке: кто знает ссылку, тот может редактировать.

### Облачный сервер

```
dotnet dist/server/Pleiada.Server.dll
```

Переменные окружения: `PORT` (по умолчанию 8787), `PLEIADA_DATA` (папка с данными, по умолчанию `./data`).

Docker: `docker build -f src/Server/Dockerfile -t pleiada-server .` и `docker run -p 8787:8787 -v pleiada:/data pleiada-server`.

Для доступа из интернета поставьте сервер за HTTPS-прокси (Caddy, nginx) с поддержкой WebSocket.

## Сборка из исходников

Нужен .NET 10 SDK.

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

- `src/web` — интерфейс (HTML/CSS/JS без сборки)
- `src/Shared/BoardHub.cs` — хранилище и синхронизация
- `src/Desktop` — окно Windows (WinForms + WebView2) со встроенным сервером
- `src/Server` — отдельный сервер для облака
